부산 ICTC 「공간별 현황」 HTML 승인 디자인 구현 · 2026-10-16

[실행 방법]
1. ZIP 파일을 전체 압축 해제합니다.
2. 폴더의 index.html을 엽니다.
3. 메인에서 '공간별'을 클릭하면 새 공간별 현황으로 이동합니다.
4. 공간명 또는 조감도(훈련실은 개별 영역)를 선택하면 기존 공간 상세페이지로 이동합니다.

[작업 범위]
- 이번 단계: 승인 공간별 현황 화면 + 홈/공간 클릭 이동(1·2단계).
- 변경된 기존 파일: '공간별_현황.html' 1개.
- 승인된 메인 index.html, 물품별 37종 및 기존 공간/물품 상세페이지는 변경하지 않았습니다.
- 여섯 공간 PNG는 기존 투명 원본의 바이너리 파일 그대로 유지합니다.

[배경 관련 설명]
- 인덱스 배경은 메인 이미지에 제목, 서버랙, 카드와 함께 합성되어 있어 별도 '빈 배경' 이미지가 없습니다.
- 이에 이번 공간별 HTML에서는 그 승인 이미지의 색감·격자·원형 패턴·은은한 광원을 CSS로 재현했습니다.
- 즉, 시각 디자인을 맞췄지만 배경의 픽셀까지 동일한 원본 이미지 복제는 아닙니다.
- 원본 인덱스 이미지는 수정하지 않았습니다.

[검증]
- 공간 PNG 6장 정상 로드 / 13개 공간 고유 링크와 상세 데이터 키 일치.
- 1672x941, 1366x768, 모바일 430x932 기준 브라우저 캡처 확인.
- 모바일 가로 스크롤 없음. HTML 화면에 의도치 않은 새 이미지 생성 없음.
- 개체정보 재집계나 이미 승인된 상세 데이터의 변경은 이번 단계에서 하지 않았습니다.

[장소명 관련 확인]
- 승인 시안의 '4층 강사대기실' 표기는 그대로 유지했습니다.
- 기존 공간 상세 데이터에는 명칭 불일치/확인 필요로 처리되어 있습니다.
- '긴급구조통제단실'과 원장 장소 '4층 강의실'의 동일 여부는 아직 확정하지 않았습니다.
